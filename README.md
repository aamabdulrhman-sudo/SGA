# SGA — منصة إدارة الجمعيات العمومية وتصويت المساهمين

منصة متكاملة متعددة المستأجرين (Multi-Tenant) لإدارة الجمعيات العامة للشركات: إدارة حسابات المستخدمين وأدوارهم، الشركات والجمعيات، سجل المساهمين، اعتماد التوكيلات، النصاب القانوني اللحظي، التصويت المرجّح بالأسهم (اعتيادي + تراكمي)، إعدادات بوابات الرسائل، وتصدير كشوف الحضور والنتائج وسجل التدقيق والمحاضر الرسمية — بواجهة عربية RTL بالكامل.

> **لا توجد أي بيانات تجريبية مسبقة** — عند أول تشغيل تُفتح صفحة إعداد إلزامية لإنشاء حساب مدير المنصة، ثم تُقفل نهائياً.

## الأدوار والصلاحيات

| الدور | الصلاحيات |
|---|---|
| **مدير المنصة** (يُنشأ عبر معالج الإعداد الأولي مرة واحدة) | جميع الصلاحيات: إدارة حسابات فريق العمل بكافة الأدوار، الشركات والجمعيات، غرفة التحكم، **إعدادات بوابات الرسائل (SMS / البريد / واتساب)** في صفحة منفصلة |
| **أمين السر** | إدارة حسابات أماني السر (إضافة / إزالة / تعطيل / إعادة تعيين كلمة المرور)، إنشاء الشركات والجمعيات، استيراد سجل المساهمين، اعتماد/رفض التوكيلات، غرفة التحكم اللحظية، تصدير Excel و **سجل التدقيق PDF** والمحضر الرسمي |
| **المساهم** | عرض أسهمه ووزنه، الحضور، البث المباشر، التصويت المرجّح، إضافة مفوض مع رفع مستند التوكيل ومتابعة الحالة والإلغاء |
| **المفوض** | عرض الموكلين والأسهم المجمّعة، حضور بالوكالة، التصويت نيابةً عنهم (فردي أو جماعي) |

## التشغيل عبر Docker (الموصى به)

```bash
git clone https://github.com/aamabdulrhman-sudo/SGA.git
cd SGA
docker compose up -d --build
```

ثم افتح: **http://\<server-ip\>:3000**

### خطوات ما بعد أول تشغيل

1. ستظهر رسالة **"الإعداد الأولي"** — افتح `/setup` وأنشئ حساب **مدير المنصة** (الاسم، اسم المستخدم، الهوية، كلمة المرور).
2. تُقفل صفحة الإعداد **نهائياً** بعد إنشاء الحساب ولا يمكن استخدامها مجدداً.
3. سجّل دخول من `/login` بتبويب **"فريق العمل"** (اسم المستخدم + كلمة المرور).
4. من `/admin/settings` أعدّ بوابات الرسائل (SMS / البريد / واتساب) — بدون بوابة مفعّلة لن يستلم المساهمون رموز التحقق (إلا في وضع التجربة `DEMO_MODE=true` حيث يظهر الرمز الشامل).
5. أنشئ الشركة والجمعية وسجل المساهمين وابدأ.

قاعدة البيانات والملفات المرفوعة تُحفظ في volumes دائمة (`sga-data`, `sga-uploads`).

### متغيرات البيئة

| المتغير | الافتراضي | الوصف |
|---|---|---|
| `JWT_SECRET` | قيمة افتراضية | مفتاح تشفير الجلسات — **غيّره في الإنتاج** |
| `DEMO_MODE` | `true` | `true` = عرض رمز OTP في الواجهة عند غياب بوابة رسائل + قبول الرمز `1234`. اضبطه `false` في الإنتاج بعد ربط البوابات |

## التشغيل بدون Docker

```bash
npm install
npm run setup     # prisma db push + generate
npm run build
npm run start -- -p 3000 -H 0.0.0.0
```

ثم افتح `/setup` لإكمال الإعداد الأولي.

## بوابات الرسائل (SMS / Email / WhatsApp)

تدعم المنصة أي بوابة ترسل عبر HTTP POST. عند طلب رمز التحقق يُرسل:

```http
POST <endpointUrl>
Authorization: Bearer <API Key>
Content-Type: application/json

{
  "to": "05xxxxxxxx",
  "message": "رمز التحقق: 1234",
  "from": "<senderName>",
  "provider": "<providerName>"
}
```

- تُجرَّب جميع القنوات المفعّلة حسب بيانات تواصل المستخدم (جوال → SMS/واتساب، بريد → Email).
- صفحة الإعدادات `/admin/settings` متاحة **لمدير المنصة فقط** وتشمل زر رسالة اختبار لكل قناة.

```
│   ├── print/audit/[id]/       # سجل التدقيق الرسمي (طباعة PDF)
│   └── api/                    # setup, auth (OTP/login), users, settings, state, vote,
│                               # attendance, proxy, agenda, assembly, shareholders, upload, exports
├── components/
│   ├── ui/                     # مكونات shadcn-style
│   ├── rooms/                  # غرفة التحكم + بوابة المساهم + بوابة المفوض
│   ├── staff-users-manager.tsx # إدارة حسابات فريق العمل
│   ├── notification-settings.tsx # إعدادات بوابات الرسائل
│   └── quorum-meter.tsx        # مؤشر النصاب القانوني اللحظي
├── lib/                        # auth (JWT + أدوار) + notifications (بوابات الإرسال) + prisma

```

## قواعد العمل المطبقة

- منع التصويت المزدوج: صوت واحد لكل مساهم لكل بند (أصالة أو وكالة — لا الاثنين)
- عند اعتماد التوكيل: يُقفل التصويت المباشر للمساهم الأصلي ويُولَّد حساب دخول للمفوض تلقائياً
- النصاب الفعلي = أسهم الحاضرين أصالة + أسهم الموكلين وكالة (بدون ازدواجية)
- التصويت التراكمي: رصيد كل مساهم = (أسهمه × عدد المقاعد) ويجب توزيعه كاملاً
- الحسابات المعطلة لا تستطيع تسجيل الدخول إطلاقاً، ولا يمكن لمدير تعطيل/حذف حسابه بنفسه
- أماني السر يديرون حسابات أماني السر فقط؛ حسابات مديري المنصة يديرها مدير المنصة حصراً
- كل عملية موثقة في سجل التدقيق (المنفذ، الدور، الوقت، IP) قابل للتصدير PDF
